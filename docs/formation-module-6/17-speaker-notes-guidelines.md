# Speaker notes — Guidelines

> Chaque `<section>` doit avoir `data-speaker-notes="..."`.

---

## Style (référence M5)

Les notes M5 sont **longues et opérationnelles** : durée, script formateur, questions, pièges, exemples observés.

**Exemple longueur M5 :** 200–800 mots pour slides clés (brise-glace, clôture).

**Module 6 cible :**
- Slides simples : 80–150 mots
- Slides clés (tourisme sexuel, casquette COVID) : 300–600 mots
- Intercalaires chapitre : 30–50 mots

---

## Structure recommandée

```
DURÉE X min.
OBJECTIF : ...
SCRIPT : ...
QUESTION GROUPE : ...
PIÈGE À ÉVITER : ...
LIEN SLIDE PRÉCÉDENTE / SUIVANTE : ...
```

## Échappement HTML

Les notes sont dans un attribut HTML. Échapper :
- `"` → `&quot;` ou utiliser apostrophes simples dans le texte français
- Pas de retours ligne bruts dans l'attribut (tout sur une ligne ou `\n` éviter)

**Astuce :** utiliser `'` français pour citations internes.

---

## Ton formateur

- Bienveillant · direct · pas moralisateur
- « Nous » / « vous » · tutoiement OK (cohérent M5)
- Exemples Puerto Miguel · Loreto · Iquitos
- Distinguer règle AKUU vs pratique locale

---

## Activités participatives à intégrer dans notes

1. **Slide 13** : « Avez-vous déjà vu un bénévole exclusif avec une famille ? Impact ? »
2. **Slide 25** : lecture carrousel · chaque participant cite une ligne rouge
3. **Slide 32** : reprendre 4 questions photo · exemple photo problématique
4. **Slide 55** : « Quelle règle sera la plus dure pour vous ? »
