# Images des espèces — galerie cliquable (Module 4)

Déposez ici une image par espèce. **Le nom du fichier doit correspondre exactement** à l'attribut `data-deck-pic` de la carte dans `index.html`.

- Format conseillé : `.jpg` (ou `.webp`), ratio paysage ~3:4 à 4:3, ≥ 1000 px de large.
- Tant qu'un fichier est absent, la carte affiche automatiquement un placeholder stylé (nom de l'espèce). Dès que le fichier est ajouté au bon nom, l'image apparaît (aucune modification de code nécessaire).
