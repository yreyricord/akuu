# Images des espèces — galerie cliquable (Module 4)

Une image par espèce. **Le nom du fichier doit correspondre exactement** à l'attribut `data-deck-pic` de la carte dans `index.html`.

- Format : `.jpg`, ratio paysage ~3:4 à 4:3
- Sources : [Zoobioparque Amaru](https://www.zoobioparqueamaru.com/nuestros-animales/) (Cuenca) + Wikimedia Commons pour espèces absentes du zoo

## Badges de protection (bénévoles)

Sur les cartes faune, attribut `data-protection` + pastille CSS (voir `deck-theme.css`) :

| Badge | Signification |
|-------|---------------|
| **PROTÉGÉ** | Interdit chasse / pêche / consommation / achat pour les bénévoles |
| **BUSHMEAT** | Gibier parfois consommé localement · ne pas demander / ne pas acheter |
| **VEDA** | Fermeture saisonnière · vérifier le calendrier local |

Restauration idempotente : `python3 scripts/restore-m4-faune-features.py`
